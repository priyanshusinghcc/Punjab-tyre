# PUNJAB TYRE – ROHTAK

Conversion-focused tyre marketplace built with:
- Next.js App Router
- Tailwind CSS
- ShadCN-style reusable UI components
- Mock inventory data for backend-ready development

## What is included
- Homepage with premium automotive hero
- Dynamic vehicle selector: brand → model → variant
- Tyre listing with filters and sorting
- WhatsApp-first lead generation flow
- Alloy wheels and car accessories sections
- Same-day fitment trust signals for Rohtak
- FAQ, SEO content, testimonials, and service blocks

## Setup
1. Install dependencies
   ```bash
   npm install
   ```

2. Add your WhatsApp number in `.env.local`
   ```bash
   NEXT_PUBLIC_WHATSAPP_NUMBER=9198XXXXXXXX
   ```

3. Run locally
   ```bash
   npm run dev
   ```

## Notes
- Replace the sample Unsplash images with your own brand photography for final production use.
- Hook `lib/data.ts` to your backend or CMS when inventory is ready.
- The primary CTA everywhere is **Get Best Price on WhatsApp**.
